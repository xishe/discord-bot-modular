# Discord-бот для RP-сообщества (модульный)

Модульная редакция Discord-бота на библиотеке `disnake` с разделением логики по расширениям в директории `cogs/`. Для сохранения данных и настроек используются JSON-файлы.

Это ранняя версия проекта. Для запуска необходимы Discord-настройки и параметры конкретного сервера.

## Структура
- `main.py` — точка входа бота.
- `cogs/` — модули логики и команд.

Запуск (при наличии заполненной конфигурации):
```bash
python main.py
```
